# v0.2.0 リリースノート

## 主な変更点

- `add <title> --body <body>` で本文付きのメモを追加できるようになりました。本文は詳細表示と検索の対象になります。
- `edit <id> --title <title>` / `--body <body>` で既存メモを編集できるようになりました。両方を同時に指定でき、`--body ""` で本文を消去できます。作成日時は維持し、更新日時は編集時刻になります。
- `MEMO_PATH` 環境変数で保存先のJSONファイルを切り替えられるようになりました。未設定または空白のみの場合は従来の `~/.memo/memos.json` を使用します。
- コマンドごとのオプション解析とヘルプを整備し、ストレージ異常系・E2E・既存データ互換性のテストを追加しました。Pull RequestとmainへのpushでCIを実行します。

## 互換性と注意事項

- v0.1.0のJSONは変換せずに利用できます。既存の `add`、`list`、`show`、`search`、`delete` の操作を引き続き利用できます。
- v0.2ではIDに0以下を指定すると入力エラーになります。
- `MEMO_PATH` による切り替えはファイル単位です。新しい保存先には既存のメモが自動コピーされません。
- グローバルな `--data-file` オプション、複数プロセスの同時更新制御は対象外です。
